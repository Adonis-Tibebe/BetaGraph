# BetaGraph

This project builds a PLN-inspired factor graph over Boolean program candidates
for the three-variable parity problem. It will evaluate candidate programs,
score co-occurring sub-expression pairs, propagate beliefs, and report the
resulting simple truth values.

The project uses a Beta-based uncertainty model alongside PLN simple truth values. The detailed
parameterization and its interaction with the PLN rules will be developed incrementally during
the sprints.
